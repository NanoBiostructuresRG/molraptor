# MOLRAPTOR: Molecular Learning via Rapid Processing of Topological Representations.
**Version 1.0.0 – Oviedo**

---

## Description
**MOLRAPTOR** is  a modular pipeline for fetching, curating, and encoding molecular datasets using PubChem data and RDKit’s Morgan fingerprinting algorithm.

---

## Purpose
The primary objective of MOLRAPTOR is to automate the preparation of molecular datasets for cheminformatics and machine learning applications. It ensures reproducibility, data integrity, and efficient encoding of chemical structures into fingerprint representations suitable for predictive modeling. The platform enables:
- **Standardized data acquisition** from PubChem, including key molecular descriptors.
- **Automated curation and validation** of chemical data to ensure structural and numeric integrity.
- **Generation of machine-learning-ready fingerprints** using RDKit’s Morgan algorithm.

## How to Run
From the project root directory, run the following command:

```bash
pip install -e . --no-deps

molraptor run --config configs/default.yaml
```

Note: You only need to run `pip install -e . --no-deps` once per environment. It enables the molraptor CLI and tracks your local edits automatically.
Reinstall only if you modify pyproject.toml, CLI entry points, or package structure.

---

## Preparation

Ensure that your input file inside `data/` includes the following file:
dataset_{training_set}.xlsx

```yaml
curate:
  required_columns:
    - PubChem CID
    - Label
    - MolecularWeight
    - Complexity
    - SMILES
```

To choose the fingerprint characteristics:

```yaml
fingerprint:
  radius: 2
  size: 1024
```

## Key Features

## Future Extensions

- **Support for Alternative Fingerprint Types (e.g., MACCS, AtomPairs)**  
  Extend the encoding module to generate multiple fingerprint types (e.g., MACCS keys, AtomPairs, or TopologicalTorsions), enabling broader descriptor coverage and compatibility with SAR and QSAR models.

- **Direct annotation with bioactivity data**    
  Integrate ChEMBL or PubChem BioAssay datasets to enrich compounds with target-specific bioactivity labels
